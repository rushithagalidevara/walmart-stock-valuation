# Walmart Stock Valuation Analysis

## Project Overview
Conducted an equity valuation analysis of Walmart using Dividend Discount Model (DDM), CAPM, and financial modeling techniques in Excel.

## Objectives
- Analyze Walmart financial statements
- Estimate intrinsic stock value
- Evaluate whether Walmart stock is undervalued or overvalued
- Compare valuation approaches using DDM and valuation multiples

## Tools & Techniques Used
- Microsoft Excel
- Financial Modeling
- Dividend Discount Model (DDM)
- CAPM
- Ratio Analysis
- Equity Valuation
